# powerbi/

Material para montar o relatório no Power BI Desktop (fase 6, P15).

| Caminho | Conteúdo |
| --- | --- |
| `medidas.dax` | Medidas DAX comentadas, organizadas em pastas de exibição |
| `tema.json` | Tema do relatório (cores e fontes) |
| `prints/` | Capturas das páginas do relatório para o README |

O passo a passo de montagem (conexão, relacionamentos, páginas e RLS) será escrito
neste arquivo no P15. Arquivos `.pbix` não são editados pelo Claude Code.
